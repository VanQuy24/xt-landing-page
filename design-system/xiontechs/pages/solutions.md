## Product copy block

Every product (and the umbrella intro) reads: tag chip → product name as a small heading (`h4` size, `blue-600`; `blue-100` on navy; it is the section's `h2`/`h3` for screen readers) → hook as the big headline (`h2` size, `h3` for sub-products; a `<p>`) → one-line body → numbers → chips, always ending with the "& more" chip (dashed; `white/40` border and `blue-100` text on navy). The hook speaks to both readers: schools that want to use the product and organisations that want something similar built.

## Motion

Overrides MASTER §6.2 "never loops" and §7 "always-on motion" for this page only, as the owner asked for a little animation.

- Transform and opacity only, 150–400ms, `--ease-out`, 50ms stagger (20ms for the grader's words). A step is `[data-s]` and shows with `data-on`; the server HTML is the final state.
- Sequences start only when the window is ≥ 35% on screen (IntersectionObserver) and stop when it leaves or the tab is hidden; a loop restarts from its first frame when it comes back.
- Loops: Parent (Tap 5s ⇄ Chat sequence), Staff (two questions, ~12s), Timetabling (step every ~4s). Clicking a Tap/Chat or stepper button stops auto-play for that window for good.
- Once: ESS (question → card → tiles), map cards, Grader (words → bars → mark count-up 800ms). A window already on screen at load keeps its final state.
- No layout shift: crossfading panels share one grid cell; chat messages have reserved slots.
- `prefers-reduced-motion`: nothing auto-plays; Parent shows the finished Chat, Staff the chart, Timetabling step 3; buttons switch states instantly.
